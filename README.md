

A premium, editorial-style recipe detail page inspired by Bon Appetit & NYT Cooking. Built with pure HTML, CSS & JavaScript.



 🔗 Live Demo
👉 https://anjaligangwar-stack.github.io/project-11/

✨ Features

- Minimal Editorial Design- Clean, aesthetic, luxury food brand feel
- Hero Section - Large food imagery with Editor's Choice badge
- Dynamic Servings- Increase / Decrease servings with JS
- Interactive Checklist- Ingredients with checkbox interaction
- Nutritional Info - Kcal, Protein, Carbs, Fat
- Author Profile- With ratings and bio
- Fully Responsive- Works on mobile, tablet, desktop
🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Custom Fonts)
- Vanilla JavaScript
- Google Fonts - Fraunces & Inter
 📁 Folder Structure
